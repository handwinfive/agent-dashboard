# 기획서 작성 에이전트

공공연구기관(KRRI) 톤을 유지하면서 배경/목적/추진방안/예산/일정/기대효과 구조의 기획서를 작성합니다.

## 그룹
**업무** — 기획서 · 발표자료 · 보고 · 실적관리

## 입력 인자
- `topic` — 기획 주제 *(필수)*
  - 타입: text / 예시: 예: 생성형 AI 기반 GTX 환승센터 디지털 트윈 고도화
- `budget` — 예산 규모 · 기본값: `미정`
  - 타입: text / 예시: 예: 40억원 / 4년
- `audience` — 대상 독자 · 기본값: `국토교통부` · 옵션: 국토교통부, 과기정통부, 내부 보고, NRF, 외부 파트너
  - 타입: select
- `goals` — 핵심 목표 *(필수)*
  - 타입: textarea / 예시: 핵심 산출물·성과지표 3~5개

## Vault 저장 권장 위치
`01.Project/A. (국가R&D) 환승역사/`

## 출력 형식
기획서 초안 (.md, 후속 .docx 변환)

## 프롬프트 템플릿

이 스킬을 호출할 때, 위 입력 인자(`{id}` 형태)를 실제 값으로 치환한 뒤 다음 프롬프트를 사용한다.

```
# 컨텍스트
- 사용자: 손승오 (KRRI 선임연구원, 한양대 교통공학 박사)
- 전문영역: 보행자 시뮬레이션(SFM) · 대심도 지하역사(GTX) · 디지털 트윈 · LiDAR/RGB-D
- Vault 위치: ~/Vaults/MyVault  (PARA 구조, CLAUDE.md 참조)
- 답변 언어: 한국어 (기술 용어는 영어 허용)

# 작업: KRRI 톤 기획서 초안 작성
- **주제**: {topic}
- **예산 규모**: {budget}
- **대상 독자**: {audience}
- **핵심 목표**:
{goals}

## 톤 가이드
- 공공연구기관 특성 반영 (정량 지표 · 사회적 가치 · 정책 연계)
- "~을 도모한다 / ~의 기반을 마련한다" 같은 행정 문체와 학술 정밀도 균형
- 미국 학계 관점에서도 통하도록 영문 키워드 병기 (예: Social Force Model)

## 구조
1. **추진 배경** (1쪽)
2. **연구 목적 및 필요성**
3. **추진 전략 및 방법론** — 단계별 마일스톤 표
4. **연차별 목표 및 산출물 (KPI 정량화)**
5. **예산 계획** (인건비 · 재료비 · 외주 · 출장)
6. **연구 추진 체계** (KRRI + 외부 컨소시엄)
7. **기대 효과 및 활용 방안** (정책 · 산업 · 학술)
8. **위험 요인 및 대응**

후속 `.docx` 변환 시 사용할 표·이미지 자리는 `[표 N]`, `[그림 N]`으로 표기.
저장 권장: `01.Project/A. (국가R&D) 환승역사/`
